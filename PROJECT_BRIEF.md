# Project brief

Source of truth: PROJECT_DISCOVERY.md. Admin scope: ADMIN_REQUIREMENTS.md.

Build a surprise website for Kimziz Global Links Ltd. in English. Prioritize import/export and car enquiries. Pages: Home, About, Services, Cars and vehicle details, Contact. Primary conversion: WhatsApp enquiry. No payments, tracking, customer accounts, or connected newsletter/enquiry forms.

Technology: Next.js App Router, TypeScript, Tailwind CSS, Lucide, Motion, Supabase Auth/Postgres, Cloudinary. npm is the working package manager. Hosting deferred; prepare for Vercel without deploying. No business-owner contact, invitations, or test messages.

All business content and vehicle inventory should be editable through a protected admin. Public rendering works from honest starter content before services are configured. Persistent admin requires user-supplied Supabase configuration; no fake authentication or browser-local CMS fallback. Cloudinary configuration follows later.

Missing facts remain unpublished. No real stock was supplied. Logo source is unresolved; temporary wordmark is explicitly documented in DESIGN_GUIDE.md. Use declarative SQL source in supabase/schemas; apply only to the dedicated project, never unrelated connected projects.
